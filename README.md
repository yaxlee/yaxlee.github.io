# yaxlee.github.io

Personal academic homepage of Yaxuan Li: https://yaxlee.github.io

Built on [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) (MIT License, see `LICENSE`),
with the styling used on [baiqi-li.github.io](https://baiqi-li.github.io/).

## Where things are
- `_pages/about.md` – all page content (about, news, publications, experience, education, skills)
- `_config.yml` – name, bio, email, location, Scholar / GitHub / LinkedIn in the sidebar
- `_data/navigation.yml` – top menu
- `images/avatar.jpg` – profile photo
- `papers/` – publication figures
- `assets/css/main.css` – styles
- `YaxuanLi.pdf` – CV (upload to the repo root)
