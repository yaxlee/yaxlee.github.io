# Yaxuan Li – personal website

Source for my academic website, based on [Jon Barron's template](https://github.com/jonbarron/jonbarron.github.io).

- `index.html` – the page
- `stylesheet.css` – styles from the template
- `images/` – profile photo, paper thumbnails, favicon
- `data/` – put `YaxuanLi-CV.pdf` here

Serve locally with `python3 -m http.server` and open http://localhost:8000.
